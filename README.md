# redhateddie.github.io

My personal homepage. Live at **https://redhateddie.github.io**.

Hand-written HTML and CSS, hosted free via GitHub Pages.

## Local preview

Just open `index.html` in a browser, or run a local dev server:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Deploy

Pushing to the `main` branch automatically updates the live site (GitHub Pages
serves the root of this repo).

## Structure

- `index.html` — the page
- `style.css` — all styling
- `README.md` — this file
